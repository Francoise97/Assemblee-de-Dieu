# Église Assemblée de Dieu — Temple de la Résurrection (Lomé - Togo)

Portail officiel et plateforme communautaire pentecôtiste pour l'Église des Assemblées de Dieu du Togo (Temple de la Résurrection, Adamavo 2, Lomé).

## 🌟 Fonctionnalités incluses

- **Histoire & Gouvernance officielle** :
  - Histoire mondiale (1914, Hot Springs) et implantation au Togo (1936).
  - Bureau Exécutif National du Togo (Mandat 2024–2029) : Rév. Dr. ADADÉ Messan, Rév. AMÉDJRO Kodjo, etc.
  - Hommage aux anciens dirigeants et pionniers (Rév. Djakouti Mitré 1987–2024, Rév. Lawson, etc.).
- **Espaces & Portails par Rôle** :
  - Pasteur / Dirigeant
  - Diacre & Comité d'église
  - Membre & Fidèle
  - Administrateur & Secrétariat
- **Prédications & Méditations** (avec filtres audio/vidéo et passages bibliques).
- **Mur d'Intercession & Prière** (dépôt et soutien de requêtes en direct).
- **Recueil de Cantiques chrétiens** (paroles, tonalités, hymnes pentecôtistes).
- **Dons, Dîmes & Offrandes** (T-Money, Flooz / Moov Money Togo, Carte bancaire).
- **Design 100% Responsive** optimisé mobile, tablette et ordinateur (sans débordement horizontal).

## 🚀 Installation & Démarrage en local (sur votre ordinateur)

### Prérequis
- Avoir installé **Node.js** (version 18 ou supérieure recommandée) : [https://nodejs.org](https://nodejs.org)
- Avoir **Git** installé : [https://git-scm.com](https://git-scm.com)

### 1. Installer les dépendances
Ouvrez votre terminal dans le dossier du projet et exécutez :
```bash
npm install
```

### 2. Lancer le serveur de développement local
```bash
npm run dev
```
Ouvrez ensuite votre navigateur sur `http://localhost:3000` (ou l'adresse affichée dans votre terminal).

### 3. Compiler pour la production
```bash
npm run build
```
